# Project preview videos

`coin-cloth-demo.mp4` is a real walkthrough of the actual Coin & Cloth
design, converted from a screen recording: scaled to 1280px wide,
re-encoded H.264 (muted, since the `<video>` element is muted regardless),
with `+faststart` for quick playback start. `coin-cloth-poster.jpg` is a
frame pulled from the video itself. This is currently the only visual on
the Coin & Cloth card — hero/gallery screenshots were tried and removed
by request.
